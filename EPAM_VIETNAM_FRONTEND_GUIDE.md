## 📄 2. Mô Hình Hợp Đồng & Chế Độ Thử Việc

EPAM Việt Nam áp dụng **2 mô hình hợp đồng chính**:

### A. Mô hình Nhân Viên Chính Thức (FTE - Full-Time Employee)

- **Thời gian thử việc (Probation):** Đúng **2 tháng (60 ngày)** theo Luật Lao động Việt Nam áp dụng cho nhân sự công nghệ trình độ cao.
- **Lương thử việc:** Hưởng **100% lương Gross** đã thỏa thuận (không bị trừ 85% như luật tối thiểu).
- **Lộ trình hợp đồng:**
  1. _Tháng 1 – 2:_ Hợp đồng thử việc (2 tháng).
  2. _Tháng 3 trở đi:_ Hợp đồng lao động xác định thời hạn (12 tháng hoặc 24 tháng).
  3. _Sau 1–2 năm:_ Hợp đồng **KHÔNG xác định thời hạn** (Chính thức vô thời hạn).
- **Quyền lợi đi kèm:**
  - Đóng BHXH, BHYT, BHTN full 100% lương Gross.
  - Bảo hiểm sức khỏe tư nhân PVI cao cấp cho bản thân & hỗ trợ người thân (vợ/chồng/con).
  - Lương tháng 13 + Thưởng hiệu suất công việc (Performance Bonus từ 1–2 tháng lương).
  - 15+ ngày phép năm có lương.
  - Trang bị phần cứng cao cấp: MacBook Pro / ThinkPad + Màn hình rời + Phụ kiện.

### B. Mô hình Contractor (EPAM Anywhere / Full-Remote)

- **Hình thức:** Hợp đồng cung cấp dịch vụ (Service Contract) thời hạn **12 tháng** (gia hạn theo năm dựa vào ngân sách dự án của Client).
- **Đặc điểm:** Thích hợp cho nhân sự thích làm Remote 100%. Không áp dụng 2 tháng thử việc truyền thống (nhận 100% rate ngay từ ngày đầu), nhưng tự nộp BHXH/Thuế TNCN theo hình thức hợp đồng dịch vụ kinh doanh cá nhân.

### 🔹 Vòng 2: Online Technical Assessment (90 – 120 phút)

- **Hình thức:** Bài test tự động trên **Codility** hoặc **MyAnatomy**.
- **Nội dung:** 15–20 câu trắc nghiệm chuyên sâu + 1–2 bài toán coding logic.
- **Bộ câu hỏi mẫu:**
  - **Trắc nghiệm JS & Web:**
    - _Event Loop Output:_ Phân tích thứ tự log của `setTimeout`, `Promise.resolve().then()`, và `console.log`.
    - _CSS Specificity:_ Tính độ ưu tiên giữa `#nav ul li.active a` vs `header .menu-item a:hover`.
    - _Flexbox vs Grid:_ Cách hoạt động của `flex-grow`, `flex-shrink`, và `flex-basis` khi container bị co lại.
  - **Bài toán Coding Logic (DSA):**
    - _Bài 1 (Array/String):_ Cho một chuỗi/mảng, đếm tần suất hoặc tìm chuỗi con dài nhất không lặp lại (_Longest Substring Without Repeating Characters_).
    - _Bài 2 (Object Manipulation):_ Viết hàm `flattenObject(obj)` để làm phẳng một Object lồng nhau nhiều cấp thành Key-Value phẳng với key dạng dot-notation (ví dụ `{"user.address.city": "HCMC"}`).

## 🎯 6. Chi Tiết Tất Cả Các Dạng Đề Live Coding Frontend (Vòng 3) & Code Mẫu

Phần Live Coding tại EPAM đánh giá **Clean Code, SOLID Principles và Bản chất JavaScript/Browser**.

### 📌 Nhóm 1: Viết Polyfill & Hàm Utility bằng Vanilla JS (Không dùng thư viện ngoài)

1. **Implement `Array.prototype.myMap` / `myFilter` / `myReduce` / `myFlat`:**
   - Viết custom mảng higher-order function hỗ trợ `thisArg`, mảng thưa (sparse array), ném ngoại lệ nếu `callback` không phải function.
2. **Implement `Promise.all` & `Promise.allSettled`:**
   - Viết hàm `promiseAll(promisesArray)` trả về Promise chứa mảng kết quả đúng thứ tự hoặc reject ngay khi có lỗi đầu tiên.
3. **Implement `debounce(fn, delay)` & `throttle(fn, limit)`:**
   - Viết `debounce` (hỗ trợ tùy chọn `leading` trigger) và `throttle` (xử lý `trailing` call).
4. **Implement Deep Clone & Object Flattener:**
   - Viết `deepClone(obj)` xử lý được tham chiếu vòng (Circular Reference dùng `WeakMap`), Date, RegExp.
   - Viết `flattenObject(obj)` chuyển `{"a": {"b": {"c": 1}}}` ➔ `{"a.b.c": 1}`.
5. **Implement Custom Event Emitter (Pub/Sub Pattern):**
   - Thiết kế class `EventEmitter` gồm `subscribe(event, listener)`, `emit(event, ...args)` và trả về hàm `unsubscribe()`.

#### Code Mẫu 1: Implement `Array.prototype.myMap`

```javascript
Array.prototype.myMap = function (callback, context) {
  if (this == null)
    throw new TypeError("Array.prototype.myMap called on null or undefined");
  if (typeof callback !== "function")
    throw new TypeError(callback + " is not a function");

  const O = Object(this);
  const len = O.length >>> 0;
  const A = new Array(len);

  for (let i = 0; i < len; i++) {
    if (i in O) {
      A[i] = callback.call(context, O[i], i, O);
    }
  }
  return A;
};
```

#### Code Mẫu 2: Implement `debounce(fn, delay)`

```javascript
function debounce(fn, delay) {
  let timerId = null;
  return function (...args) {
    const context = this;
    if (timerId) clearTimeout(timerId);
    timerId = setTimeout(() => {
      fn.apply(context, args);
    }, delay);
  };
}
```

#### Code Mẫu: AutoComplete Search Component với API Debounce (React TypeScript)

```tsx
import React, { useState, useEffect } from "react";

export const AutoComplete = ({ fetchSuggestions }) => {
  const [query, setQuery] = useState("");
  const [results, setResults] = useState([]);
  const [isLoading, setIsLoading] = useState(false);
  const [error, setError] = useState(null);

  useEffect(() => {
    if (!query.trim()) {
      setResults([]);
      return;
    }

    const timer = setTimeout(async () => {
      setIsLoading(true);
      setError(null);
      try {
        const data = await fetchSuggestions(query);
        setResults(data);
      } catch (err) {
        setError("Failed to fetch suggestions");
      } finally {
        setIsLoading(false);
      }
    }, 300);

    return () => clearTimeout(timer);
  }, [query, fetchSuggestions]);

  return (
    <div className="autocomplete-container">
      <input
        type="text"
        value={query}
        onChange={(e) => setQuery(e.target.value)}
        placeholder="Search..."
        aria-label="Search suggestions"
      />
      {isLoading && <div className="spinner">Loading...</div>}
      {error && <div className="error-message">{error}</div>}
      {results.length > 0 && (
        <ul className="suggestions-list">
          {results.map((item, idx) => (
            <li key={idx}>{item}</li>
          ))}
        </ul>
      )}
    </div>
  );
};
```

### 📌 Nhóm 3: Refactoring Code Xấu & React Performance Optimization

1. **Tách Monolithic Component (Code 200 dòng):**
   - Tách logic fetch data ra khỏi UI bằng **Custom Hook** (ví dụ `useFetch`).
   - Tách UI rối rắm thành các Sub-component nhỏ nguyên tử (Atomic Components).
2. **Khắc phục Re-render Thừa:**
   - Sử dụng `useCallback` cho callback handler truyền xuống con và `useMemo` cho tính toán nặng.
   - Tránh truyền inline objects (`style={{ color: 'red' }}`) hoặc inline arrow functions trong JSX.
3. **Khắc phục Memory Leak:**
   - Cleanup event listener / `setInterval` trong `useEffect`.
   - Sử dụng `AbortController` để hủy HTTP request chưa hoàn thành khi component unmount.
